# UniXNU-enuma

小米平板5 Pro 5G / SM8250-AC的iPadOS17.7.11移植。当前主线按用户D-170要求：准备尽可能完整的启动链，采集实际报错并逐轮修复；单点早停仅作必要备用。

已实际生成29组件的实验系统预链接，并固定同SoC [UniXNU-umi](https://github.com/reAAAq/UniXNU-umi/tree/3eb72578597d2ca16471b172d45eddc096a34a04)作为ADT、RAM载荷、PMGR/UFS和CPU显示复用源。已生成完整结构ADT和96MiB真实FAT，实际loader解析主机检查通过；v3只读RAM运输和13项同次报告已实现并完成构建/打包资格，运行时发现、root及可见错误通道仍待闭合，尚无进入XNU或iPadOS的实机证据。当前D-196：真实FrameBufferBltLib GOP后端已通过主机及QEMU RAM自测，双链路同次只读候选S-008已资格，发布后临时启动；物理地址、缓存与下游路由未闭合，真实GOP尚未发布。原始影音本地，所有已执行候选不重试。
