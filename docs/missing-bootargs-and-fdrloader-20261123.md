## 参数

1. **`sheng-smp=1`：r54 无，预计单核。** sheng、sirius、pipa、OPi5 均配置：sheng 的缩写 `smp=1` 依 `docs/sheng-donor-branches-20261123.md:343` 的同 donor 配置为 `sheng-smp=1`；sirius、OPi5 见上列比较，pipa `board.toml:228-234`。本地源码核对记录 `docs/enuma-lite-watchdog-args-check-20261122.md:8-12` 指向 ArmCpu `ArmCpu.cpp:222-224,439-442`：未启用时拒绝 secondary nub，不走该组件二级核启动。`docs/SESSION-HANDOFF-20261120.md:46` 记录 ADT 一 running、七 waiting。故按该路径静态推断 r54 只有 boot CPU；缺 r54 的运行时 processor count，不能称实测一核。打开 SMP 还需本板 CPU topology、IPI 路径及并发专项审查，不能只补此参数。
2. **`dk=0`：sirius 用，其余三者上述固定配置未见；r54 无。** `UniXNU/docs/.vitepress/device-records/sirius-huajifruit.toml:385-389` 原记录：“DK: AppleUserHIDEventDriver-0x100000249 waiting for server com.apple.driverkit.AppleUserHIDDrivers-100000249”，随后 “user server timeout”；driverkitd 已启动但该 server 未 exec，故无 IOHIDEvent。该记录称 XNU `IOUserServer.cpp` 的 `gIODKDebug` 未置 `kIODKEnable` 时 `IOService.cpp:3910` 不匹配 dext；改 `dk=0` 并使用组合 keyboard+touch 设备后，内核 IOHIDEventDriver 附着且 Setup 对触摸有响应。仅 touch-only personality 在该 donor 反而不匹配内核 event driver，不能把 `dk=0` 当成单独保证触摸的修复；它同时禁用所有 DriverKit 驱动。enuma 是否遇到相同 server timeout 未证。
3. **`offline-mobile-graphics-client=1`：sheng、sirius 用；pipa、OPi5 上述配置未见；r54 无。** 固定 UniXNU `patches/xnu/offline-component-load-probes.patch:66-87`：`offline-mobile-graphics-load` 先加载 family，成功后分别以 `offline-legacy-register` 调显示注册、以 client 参数调另一个 probe。`:146-178` 的 client probe 仅尝试分配抽象类与 `IOMobileFramebufferUserClient`、初始化、调用三个 selector、释放并记录诊断；它不是注册 framebuffer 用户客户端的必需开关，也不是显示归档。r28 已记录 `MobileGestaltHelper`、`IOMFB_FDR_Loader` 成功打开板级客户端（`docs/enuma-r28-device-20261123.md:33-39`）。因此缺该参数不解释客户端无法注册；probe 的额外 selector 调用并非无副作用，不能盲加。上述是上游 patch 语义；r54 最终目标文件是否仍与该实现逐字节一致未核。
4. **unit-scale：四者用 2，r54 无；运行时路径不等价静态 ADT。** pipa `board.toml:207-209` 称每逻辑点每轴两像素，记录 1x 曾使锁屏半尺寸；sheng/sirius/OPi5 见比较。sheng `package/LegacyDisplayProbe.cpp:437,455-482` 在映射回调解析参数，核对或发布 `/chosen/display-scale` 与 `/chosen/display-rotation`，失败回滚；逐行摘录及 enuma r5 回调对照见 `docs/unit-scale-investigation-20261123.md:7-24`。r54 `out/ufs-sm8250-fbfill3-20261123-r54/device/board.toml:164` 静态设 `display-scale=2`，且读回参数无该开关；r40 实际 ADT 包含 2（`docs/repo-diff-adt-bootargs-20261123.md:7,23`）。未核 r54 最终 ADT 的 rotation 和实际回调实现，不能声称运行时已写或消费 rotation；单加参数也不保证 enuma 的回调实现 sheng 路径。
5. **内核调优：sheng、sirius、pipa 使用 `kt_fixed_zones=120 -no_slto_panic ml-timeout-lock-panic-scale=40`，OPi5 比较配置未列，r54 未列。** sheng/sirius 见比较文档 `:76,80,82`，pipa `board.toml:180-185`。官方 `UniXNU/docs/xnu/boot-arguments.md:43-44` 分别描述抑制 SLTO panic、固定 kernel trace zone 数；`UniXNU/docs/.vitepress/device-records/zizhan.toml:52` 记录 lock panic scale 为 40，但本次未核该 donor 内核具体计算及默认值。缺少这些参数不证明已发生内核超时或 trace 耗尽，也不能推断加上能修显示；抑制 panic 会改变诊断行为。
